# Анализ цен на недвижимость — Республика Дагестан

Streamlit-приложение с машинным обучением для анализа и прогнозирования цен на жилье в Дагестане.

## Данные

| Файл | Описание |
|------|----------|
| `data.xls` | Средняя цена за 1 м² по кварталам (2021–2025), Росстат |
| `avito.xlsx` | Объявления о продаже квартир с Avito (Махачкала) |
| `05.rosstat.gov.ru.pdf.url` | Ссылка на PDF с индексами цен Росстата |

## Возможности

- **Динамика цен за м²** — график по кварталам (2021–2025) с ML-прогнозом на 2026 год
- **Индексы цен Росстата** — поквартальные индексы и накопленный рост
- **Анализ Avito** — распределение цен, корреляции, карта объектов
- **ML-модель** — RandomForest для предсказания цены квартиры по характеристикам
- **Калькулятор** — интерактивный прогноз цены по площади, комнатам, этажу

## ML-алгоритмы

1. **Прогноз цен за м²**: Линейная регрессия, Полиномиальная регрессия, Gradient Boosting
2. **Прогноз цены квартиры**: Random Forest Regressor

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` — основное Streamlit-приложение с ML и визуализацией
- `code.py` — предыдущая версия приложения
- `data.xls` — данные Росстата
- `avito.xlsx` — данные Avito
